# Rex Legend

第三人稱 3D 動作探索遊戲，用純前端 Three.js 打造，開瀏覽器就能玩，不需安裝任何套件。

在開放的草原上探索、揮劍連段、施放閃電與火焰魔法、丟炸彈、累積經驗值升級，並在擊殺足夠敵人後迎戰種類各異的巨型 Boss。

## 線上遊玩

本專案是 ES module 前端，需要透過 HTTP 伺服器開啟（不能直接用 `file://` 打開 `index.html`）。

### 方式一：GitHub Pages（推薦，讓任何人線上玩）

1. 把專案推上 GitHub
2. 到 repo 的 **Settings → Pages**
3. Source 選 **Deploy from a branch**，branch 選 `main`、資料夾選 `/ (root)`
4. 稍等片刻，即可透過 `https://<你的帳號>.github.io/<repo 名稱>/` 遊玩

### 方式二：本機執行

需要 Python 3：

```bash
python serve.py
```

然後開瀏覽器前往 http://localhost:8010

（`serve.py` 是一個帶 no-cache 標頭的簡易靜態伺服器，方便開發時修改即時生效。）

也可以用任何靜態伺服器，例如：

```bash
npx serve .
# 或
python -m http.server 8010
```

## 操作方式

| 按鍵 | 動作 |
|------|------|
| W A S D | 移動 |
| 滑鼠 | 轉動視角 |
| 空白鍵 | 跳躍 |
| Caps Lock | 切換奔跑 |
| Shift | 平行移動（上半身固定朝前） |
| 滑鼠左鍵（按住） | 連續劈砍（5 段連段，第 5 段大橫掃並射出劍氣） |
| 滑鼠中鍵 | 閃避空翻 |
| 滑鼠右鍵（點按） | 閃電魔法（以自身為圓心範圍落雷） |
| 滑鼠右鍵（長按 ≥1 秒） | 火焰魔法（前方長條噴射，按住持續施放） |
| E | 拾取附近炸彈 / 投擲庫存炸彈 |
| ESC | 開啟選單（怪物數量、炸彈數量、滑鼠靈敏度等） |

遊戲會自動偵測平台，桌機用鍵鼠、手機/平板顯示觸控介面。

### 手機 / 觸控操作

| 位置 | 動作 |
|------|------|
| 螢幕左半 | 虛擬搖桿移動（預設奔跑） |
| 螢幕右半（拖曳） | 轉動視角 |
| 螢幕右半（點一下） | 攻擊 |
| 螢幕右半（快速點兩下） | 施放魔法 |
| 上方「💣 炸彈」鈕 | 拾取 / 投擲炸彈 |
| 最上方「☰ 選單」鈕 | 開啟 / 關閉選單 |

## 遊戲特色

- **第三人稱角色**：多關節人形、走跑動畫、五官朝向清楚，右手持劍
- **連段攻擊**：按住左鍵打出 5 段連段，收尾大橫掃並射出可貫穿的劍氣
- **魔法系統**：閃電（範圍落雷）、火焰（長條噴射），威力與範圍隨等級提升
- **敵人種類**：史萊姆、史萊姆頭目、跳躍踢擊的兔子
- **巨型 Boss**：累積擊殺達標後，依擊殺最多的怪物種類召喚對應巨型 Boss，各有專屬華麗技能（震地 / 召喚 / 飛撲砸地）
- **龍捲風**：施放閃電時同時捲起龍捲風，多層旋轉雲氣把周圍怪物捲著繞玩家旋轉並持續傷害
- **炸彈道具**：地上隨機出現，可踩爆、可拾取收進庫存、可拋擲，超大規模多層爆炸特效並將怪物擊飛
- **可破壞環境**：樹木（多種、可重生）、石頭（大中小、分件炸開）、木箱、木桶、水晶等，以及可分區炸毀的房子
- **可進入的建築**：小木屋與三層樓建築，內部有樓梯可上樓（玩家與怪物皆可），也能整棟炸毀
- **經驗值與升級**：擊殺獲得經驗，升級提升血量上限與魔法強度
- **跨平台**：自動偵測手機 / PC，切換觸控或鍵鼠操作
- **效能優化**：遠方敵人採 LOD 簡化運算，支援大量怪物同屏

## 技術

- [Three.js](https://threejs.org/) 0.160（透過 CDN import map 載入，無需安裝）
- 純 JavaScript ES modules，無建置流程
- HTML + CSS 介面（HUD、選單、提示）

## 專案結構

```
GAME_Rex_Legend/
├─ index.html          入口、HUD、選單
├─ styles.css          介面樣式
├─ serve.py            本機開發用 no-cache 伺服器
└─ src/
   ├─ config.js        所有可調參數（手感、難度、數值）
   ├─ input.js         鍵鼠輸入、滑鼠鎖定、觸控搖桿與手勢
   ├─ world.js         場景、燈光、地形、可破壞障礙物與建築、碰撞
   ├─ player.js        角色、連段攻擊、動畫、血量、閃避
   ├─ slime.js         史萊姆（含頭目）
   ├─ rabbit.js        兔子敵人
   ├─ megaboss.js      巨型 Boss 與專屬技能、誇張死亡特效
   ├─ magic.js         閃電、龍捲風、火焰魔法與劍氣
   ├─ bomb.js          炸彈道具、拾取、投擲、爆炸
   ├─ progression.js   經驗值與等級系統
   └─ main.js          遊戲主迴圈、攝影機、整合各系統
```

## 調整與擴充

大部分手感與數值都集中在 `src/config.js`，例如移動速度、跳躍、劍的傷害與連段、各種魔法範圍、敵人血量與速度、Boss 召喚門檻、炸彈範圍等，改完重整網頁即可生效。
